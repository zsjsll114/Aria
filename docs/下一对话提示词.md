## 最近完成的修复（本轮对话）

### 1. 词云变焦功能
- **功能**：活动行播放时自动缩放到统一字号，非活动行等比缩放（比例尺效果）
- **实现**：
  - `wordcloudCurrentScale` 变量记录当前缩放值，通过 Lerp 阻尼插值平滑过渡
  - `getWordcloudTargetFontRem()` 根据窗口宽度动态返回目标字号（2.0~4.0rem）
  - `transform: translate(X, Y) scale(S)` + `transform-origin: 0 0` 简化坐标计算
  - `lineEl.dataset.wcFontSize` 保存每行随机原始字号供变焦计算
  - `targetScale = getWordcloudTargetFontRem() / rawFont`，限制 0.3~3
- **文件**：`src/app.js`（约780行 `getWordcloudTargetFontRem`，约1040行 `updateWordcloudCamera`）、`歌词播放器.html`（同步）

### 2. 词云滚轮缩放 + 3s超时
- **功能**：词云模式下滚轮缩放整个词云（以鼠标位置为中心），3s后恢复自动跟焦
- **实现**：
  - 滚轮事件中检测 `view-wordcloud` 模式，计算鼠标位置对应的画布坐标
  - 缩放后调整平移使鼠标位置不变：`translateX = mouseX - canvasXBefore * newScale`
  - `wcZoomTimer` 3秒超时，期间 `updateWordcloudCamera` 提前 return
  - 词云模式下滚轮不设 `isUserScrolling`，不干扰逐字高亮
- **文件**：`src/app.js`（约2610行滚轮事件）、`歌词播放器.html`（同步）

### 3. 词云长按拖动 + 点击切行区分
- **功能**：长按拖动移动词云画布，短点击切换歌词行
- **实现**：
  - `wcDragState` 全局变量记录拖动状态（startX/Y, startXform/Yform, moved）
  - `WC_DRAG_THRESHOLD = 6px` 超过此距离判定为拖动
  - 拖动时设 `cursor: grabbing`，暂停自动跟焦
  - 拖动结束后设 `wcSuppressClick = true`（100ms），在 capture 阶段拦截 click 事件
  - 支持鼠标和触摸事件
- **文件**：`src/app.js`（约2665行拖动逻辑）、`歌词播放器.html`（同步）

### 4. 滚轮不暂停逐字高亮
- **问题**：默认模式下滚轮滚动时逐字高亮特效暂停（`!isUserScrolling` 跳过更新）
- **修复**：移除逐字高亮更新的 `!isUserScrolling` 条件，滚轮时仍更新当前播放进度
- **文件**：`src/app.js`（约1180行）、`歌词播放器.html`（本身无此条件，无需改）

### 5. 视图模式弹窗布局优化
- **修改**：`view-mode-cards` 改为 `flex-wrap: wrap`，每行两个（`flex: 1 1 calc(50% - 8px)`，`min-width: 200px`），`max-height: 60vh` + `overflow-y: auto`
- **文件**：`src/styles/viewmode.css`（约77行）、`歌词播放器.html`（同步）

### 6. oiapi.net 备用歌词 API
- **问题**：vkeys 对部分 QQ 音乐歌曲返回 code 500 或歌词为空
- **方案**：新增 `fetchLyricWithFallback(songId, source)`，先 vkeys，失败回退 oiapi.net
  - oiapi.net QRC 格式与 `parseYrc` 兼容，映射为 `{ yrc: data.content }`
  - 替换了所有4处歌词获取点（主播放、预加载、AMLL补充、音源互转）
- **文件**：`src/app.js`（约3193行 `fetchLyricFromOiapi` + `fetchLyricWithFallback`）、`歌词播放器.html`（同步）

### 7. parseYrc 修复 \r\n + original 字段
- **问题1**：vkeys YRC 数据使用 `\r\n` 换行，`split('\n')` 后每行末尾有 `\r`，可能导致解析异常
- **修复1**：`yrcText.replace(/\r\n/g, '\n').split('\n')` 统一换行符（parseYrc 和 parseRoma 均修复）
- **问题2**：`parseYrc` 返回 `original: null`，导致 `mergeLyrics` 中翻译匹配失败、渲染回退异常
- **修复2**：从 words 拼接生成 `original: fullText`
- **文件**：`src/app.js`（约42行 parseYrc，约86行 parseRoma）、`歌词播放器.html`（同步）

### 8. 飞入/词云样式泄漏到普通模式
- **问题**：从飞入或词云模式切回普通模式时，歌词未重新渲染，模式特有的内联样式残留
- **修复**：`switchView` 中将 `wasFlyin && mode !== 'flyin'` 扩展为 `(wasFlyin || wasWordcloud) && mode !== 'flyin' && mode !== 'wordcloud'`，切回普通模式时重新 `renderLyrics`
- **文件**：`src/app.js`（约10470行）、`歌词播放器.html`（约15693行）

### 9. cleanupWordCloud 清理所有状态
- 切回普通模式时清理 `wcZoomTimer`、`wcDragState`、`wcSuppressClick`
- **文件**：`src/app.js`（约1098行）、`歌词播放器.html`（同步）

## 代际计数器模式说明
封面和背景切换都使用代际计数器模式：
- 每次调用递增全局计数器（`coverGen` / `bgGen`）
- 回调闭包捕获本次调用的代际值 `myGen`
- 回调执行时先检查 `myGen !== coverGen` → 被新调用取代就放弃
- 再检查目标层是否已可见 → 已执行过就跳过
