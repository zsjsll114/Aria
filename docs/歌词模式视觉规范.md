# 歌词模式视觉规范

覆盖主界面所有歌词视觉模式与桌面歌词窗口。这里写的是硬规则和既定参数，改动前先读完；
每条规则背后都有一次真实的回归事故，不要因为"看起来可以优化"就绕开。

## 通用硬规则

1. **蒙德里安（tunnel）的词距与碰撞膨胀必须成对改。** 词块碰撞检测的 AABB
   膨胀系数 `inflate` 在直排（`mosaicTilt` 关）下是 1.0，倾斜模式是 1.42。
   行内词距（CJK 0.008 / 拉丁 0.020~0.028 / 带空格 0.040）小于
   `0.02 × (相邻词宽之和)` 时，膨胀盒会互相重叠，碰撞解决逻辑会把词逐个下推一行，
   排版立刻退化成锯齿。改词距前先算一遍这个不等式。
2. **蒙德里安栅格是点缀，不是底纹。** 生成概率 0.35/块，线色不透明度 ≤0x8C，
   不强制任何块（包括最大块）带栅格。历史教训：90% + 强制最大块导致整屏网格，
   30% + 无保底又被投诉"整组没有方格"——0.35 + 保底取消是两次投诉的平衡点，
   再动之前先把两个版本的截图放一起看。
3. **蒙德里安背景图案按段落(section)稳定。** 缓存键只含 sectionId，不含 groupId。
   色块的几何与颜色靠 `.t-m-block` 的 1.6s CSS 过渡平滑变形；
   栅格子层用 opacity 渐隐渐显，不要用 display 切换（background-image 不可过渡）。
4. **桌面歌词横向定位只走锚点。** `lyrics.html` 的 `anchorCenterX` 是歌词盒中点的
   逻辑 X，窗口左边缘 = 锚点 − 宽/2，resize 时把 x 传给 `desktop_lyrics_resize`。
   任何"基于当前位置 + Δ"的写法都会经物理↔逻辑坐标取整而累积漂移。
   锚点不跨会话持久化：重启按上次左边缘落位，首曲宽度不同也不允许横向跳动。
5. **桌面歌词高亮层裁剪盒上下各留 0.35em。** `.word .fill` 用 `overflow:hidden`
   做进度揭示，g/j/y 的下伸部超出行盒，不放宽就会露出白色底层。
   内层彩色字用 `top:0.35em` 补偿对齐，改了放宽量必须同步改补偿值。
6. **主窗口显示时机 = 首帧绘制之后。** `page_loaded` 信标在两层 rAF 后才发，
   DOMContentLoaded 时背景层还没画，提前 show 会闪出未绘制的透明帧。
   信标有 800ms 兜底，rAF 被节流时窗口也能显示。

## 新模式：活字（Letterpress）

### 一句话

歌词是一块正在排版中的铅字版面：唱到哪个字，那个字就被"压印"上墨；整句唱完，
版面作为一张色纸滑出，下一张滑入。

### 与现有模式的差异

词云是散点，PV 是分镜，蒙德里安是色块拼画，隧道是纵深。活字模式的视觉核心是
**排印本身**——字体、字重、基线、墨色深浅就是画面，没有背景图形 competing。
想要"看歌词本身"的用户会停留在这个模式。

### 视觉结构（自下而上）

| 层 | 内容 |
|---|---|
| 底 | 深中性色（`#111` 系），不随封面变色 |
| 色纸 | 一块占据 60%~78% 宽的非对称矩形，颜色由段落情绪决定（单色，低饱和） |
| 版心 | 色纸上的文字区：主歌词大字（白/墨，视色纸明度），翻译小字居下 |
| 巨物 | 段落关键词的**超大号压印字**，钉在九宫格锚点上，跨句不换位 |
| 进度 | 当前字的墨色揭示（mask），已唱字保持满墨 |

### 分镜与分组

直接复用 `core/lyricSceneGrouper.buildSceneGroups`，参数 `maxLines=6, maxSpanSec=7`。
组的 kind 判定沿用现有实现；kind 决定色纸颜色与压印力度，映射如下：

| kind | 色纸 | 压印力度 | 巨物 |
|---|---|---|---|
| chorus | 亮纸（米白/浅金） | 重（scale 1.16→1.0，余晖 12px） | 有，词取副歌首关键词 |
| lift | 亮纸 | 重 | 有 |
| verse | 中性纸（灰青/灰绿） | 中 | 无 |
| break | 深纸 | 轻（无余晖） | 无 |
| breath / outro | 深纸 | 轻 | 无 |

### 版式池（确定性轮换，同参数同结果）

每段落按 `段序号 % 池长` 取版式，不做随机。初版四个：

| 版式 | 色纸区域 | 对齐 | 主字号 | 入场 |
|---|---|---|---|---|
| 对页 | x .08~.92, y .18~.78 | center | 1.0 | 整纸上滑 |
| 海报版 | x .10~.66, y .14~.82 | left | 1.12 | 纸从左滑入 |
| 便签 | x .30~.92, y .22~.62 | right | 0.88 | 纸从右滑入 |
| 横幅 | x .06~.94, y .30~.62 | center | 1.05 | 纸下拉 |

入场出场统一 0.6s 缝合转场（旧纸滑出与新纸滑入重叠），handoff 不短于 0.4s。

### 逐字规则

粒度：CJK 每字一单元，拉丁整词一单元（与主界面一致）。
揭示用 `mask-image: linear-gradient(to right, #000 var(--reveal), transparent var(--reveal))`
打在字元素上，**禁止动画 width**（会逐字重排）。`--reveal` 由 rAF 写入，跳过未变化的百分比。

### 巨物

每段落取一个关键词（AI 的 `emotion_words` 优先，无 AI 走词典投票），字号 = 主字号 × 3.2，
钉在九宫格锚点（段落序号决定锚点，在 右上/左下/右下 间轮换）。压印动画：scale 1.3→1.0
+ 墨色由透明到实，时长 = min(0.9s, 段时长 × 0.4)。巨物在整段期间保持，段落结束随纸滑出。

### 降级路径

- 无 AI：词典投票（zh/en 各 5~6 词）定 kind 的强调色；巨物取该段最长 CJK 词。
- 无逐字数据：按行区间均分合成 words（`PVLyricLayout` 已有该兜底）。
- 低性能档：关余晖、巨物不加压印动画只做淡入。

### 验收清单

- [ ] 同一首歌两次渲染排版完全一致（种子 = 标题 hash，无随机数）
- [ ] 整句唱完时所有字都在同一条基线上（无锯齿、无错位）
- [ ] 巨物不与版心文字重叠（锚点互斥）
- [ ] 色纸切换为重叠转场，无黑场无白闪
- [ ] 任意字号（0.7~1.6）下文字不出色纸边界
- [ ] 暂停时揭示停在当前字，恢复后继续推进
