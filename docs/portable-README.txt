Aria 歌词播放器（绿色便携版）使用说明
=====================================

一、怎么用
  1. 把整个 AriaPortable 文件夹复制到任意电脑（建议放到不含中文、不含空格的路径，例如 D:\Aria）。
     如果拿到的是 zip 压缩包，请务必使用 7-Zip / WinRAR 完整解压（不要只解压部分文件）。
  2. 双击「StartAria.bat」：后端完全后台运行（无黑色控制台窗口），
     约 3 秒后浏览器自动打开播放器界面。
  3. 双击「Aria.exe」：桌面版（Tauri 窗口，透明标题栏，同样无黑框）。
     两种入口二选一，用完后运行「StopAria.bat」停止后台服务。

二、包含的功能
  - 在线多源搜索/播放：网易云、QQ音乐、酷狗、酷我
  - 逐字歌词高亮、情感词上色、词云/PV/全景/飞入 等视觉模式
  - 歌单、收藏、历史、播放统计、均衡器
  - 自建服务（QQ音乐 / 酷狗音乐 / 网易云音乐）：扫码/手机号登录、每日推荐、歌单、收藏
  - 本地音乐：把音频文件放入 local_music 文件夹（每首歌一个子文件夹）
    或在界面「本地音乐」里上传导入
  - 听歌识曲（Shazam 声学指纹）：点击识曲按钮录音/上传即可识别

三、免安装依赖说明
  - 后端 server.exe：已用 PyInstaller 打包，无需 Python。
  - 便携 Node：runtime/node.exe，识曲侧车与三个自建平台副进程共用，无需安装 Node.js。

四、注意事项
  - 端口占用：8001（主服务）/ 18089（识曲）/ 3100（酷狗）/ 3200（QQ）/ 3201（网易云）。
    若端口被占用，server.exe 会自动清理旧进程残留。
  - 登录态：登录后保存在 cache/selfhost_login.json，下次启动自动恢复，扫码一次长期有效。
  - 绿色版压缩包未包含任何个人配置（本地设置、登录态、缓存、本地音乐都不随包分发），
    首次运行是全新环境。
  - 杀毒软件：若提示可疑，请将本文件夹加入白名单（PyInstaller 单文件偶有误报）。

五、想删除？
  直接删除整个文件夹即可，无注册表、无系统服务残留。
