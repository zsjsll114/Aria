## 拍摄建议

- **同一首歌、同一段副歌**拍全部模式——九张图风格统一，首屏观感翻倍
- 尺寸 1920×1080（或窗口等比），PNG 格式；深色封面/夜色氛围的歌最能体现
  活字、霓虹、蒙德里安的质感
- PV / 蒙德里安 / 霓虹开 AI 情绪分析后再截（构图与配色贴合歌词情绪）
- 视频（可选）：每个模式 5~10 秒 mp4 放本目录或 Release 附件，
  README 用 `<video>` 或链接引用
