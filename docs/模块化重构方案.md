> 均已删除，JS 分片架构早已落地（见 `web/src/app/*.js` 与 AGENTS.md）。仅作重构历史参考，勿据此修改代码。

## 二、重构策略：渐进式拆分

**核心原则**：
1. **保持功能完整** —— 每步拆分后都能正常运行
2. **零构建工具** —— 纯 ES Module，浏览器原生支持
3. **双写过渡** —— 新旧代码并存，逐步替换
4. **从叶子到根** —— 先拆无依赖的工具函数，最后拆核心引擎

### 阶段 2：基础设施层（状态 + DOM + 事件总线）

**目标**：建立模块间通信机制，替代 IIFE 闭包共享。

#### 2.1 创建 `src/infrastructure/state.js`

```javascript

export const state = {
    // 播放器状态
    isPlaying: false,
    currentTime: 0,
    volume: 80,
    playMode: 'sequence',
    
    // 歌词状态
    lyrics: [],
    activeLineIndex: -1,
    lineElements: [],
    
    // 播放列表
    playlist: [],
    currentTrackIndex: 0,
    
    // AI
    aiThemeCache: {},
    currentAiTheme: null,
    aiEmotionWords: [],
    
    // 设置
    appSettings: null, // 由 loadSettings 填充
};

export function setState(updates) {
    Object.assign(state, updates);
}
```

#### 2.2 创建 `src/infrastructure/dom.js`

```javascript
// 集中管理所有 DOM 引用
export const dom = {
    audio: null,
    playBtn: null,
    // ... 40+ 个元素
};

export function initDom() {
    const get = id => document.getElementById(id);
    dom.audio = get('audioPlayer');
    dom.playBtn = get('playBtn');
    // ... 初始化所有引用
}
```

#### 2.3 创建 `src/infrastructure/eventBus.js`

```javascript
// 轻量级事件总线，替代函数间直接调用
const listeners = new Map();

export const eventBus = {
    on(event, handler) {
        if (!listeners.has(event)) listeners.set(event, new Set());
        listeners.get(event).add(handler);
        return () => listeners.get(event)?.delete(handler);
    },
    emit(event, ...args) {
        listeners.get(event)?.forEach(h => h(...args));
    },
};

export const EVENTS = {
    SONG_CHANGED: 'song:changed',
    PLAY: 'audio:play',
    PAUSE: 'audio:pause',
    LYRICS_LOADED: 'lyrics:loaded',
    // ... 更多事件
};
```

**过渡方案**：在 IIFE 中同时保留旧变量和新模块：
```javascript
// index.html 的 IIFE 顶部
import { state } from './src/infrastructure/state.js';
import { dom, initDom } from './src/infrastructure/dom.js';

// 双写：旧变量指向新模块
let isPlaying = state.isPlaying; // 实际上应该统一使用 state
```

**方案A：直接设置 style.fontSize（已实施）**

.view-flyin .line {

@container (max-height: 200px) {

## 七、风险与应对

| 风险 | 应对策略 |
|------|----------|
| 拆分后功能丢失 | 每阶段完成后完整测试，保留原始文件备份 |
| 循环依赖 | 使用 eventBus 解耦，避免模块间直接 import |
